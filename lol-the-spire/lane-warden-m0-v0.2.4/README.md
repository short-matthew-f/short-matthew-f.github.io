# Lane Warden M0 v0.2.4 — ATT-001

Immutable exploratory build for **Attention & Offscreen Threat Signaling** over the frozen R01-C Twin Toll candidate.

The preceding v0.2.3 human Siege + delay run won at 4:25 with South Bastion at 0.6%, producing the intended informed-play sacrifice race.
