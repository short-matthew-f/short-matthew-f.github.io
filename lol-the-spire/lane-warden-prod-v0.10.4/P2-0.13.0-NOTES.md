# Lane Warden P2-0.13.0 — Reward Engine + Victory Reward Screen

Deployed in the existing stable production install scope.

## First P2 seam

- Outer Approach victory now generates a deterministic, persistent normal reward packet instead of the placeholder +180 Salvage resolution.
- Normal victory grants 140 Salvage plus one Growth component; a deterministic 25% Bonus-component roll is supported.
- Components can be claimed or skipped independently.
- Skip value is shown before confirmation and persists immediately.
- Component, category, and packet reroll primitives are implemented and only enabled when a run has entitlement.
- Packet generation, rerolls, claims, skips, and finalization write reward-history receipts.
- Reload/background lifecycle returns to the same unresolved packet.

## Run growth

P2 save migration adds act normal-battle count, owned Units/Towers, Commander improvements, Relics, Upgrades, Capacity, Logistics credits, reward history, pending packet, and thesis state.

Minimum catalogue shipped for systems proof:

- 4 Unit unlocks
- 4 Tower unlocks
- 5 Commander improvements
- 10 Relics
- 5 Upgrades
- 3 Capacity rewards
- 5 Logistics rewards

The reward-modifier proof set includes +1 offer width, first component reroll free, increased Bonus chance, and improved skip Salvage.

## Thesis floor

The first battle establishes a simple run thesis from deployment. At most one eligible Growth component per packet receives one compatible guaranteed offer, and the reward screen discloses that guarantee.

## Immediate battle proof

After the first packet is fully resolved, the run returns to the map with Split Causeway available as a P2 reward proving ground. It intentionally reuses the Outer Approach combat model for this build so acquired content can be verified before new encounter mechanics are authored.

Owned-content filtering is enforced in deployment. Capacity changes the displayed/legal deployment allowance. Unit/Tower unlocks become deployable. Commander, Upgrade, and Relic effects are applied to the next battle.

Outer Approach balance values were not retuned in this build.
