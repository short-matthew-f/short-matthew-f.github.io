# P1-0.11.2 — UI Repair

**Date:** 2026-08-23  
**Status:** ACTIVE UI ITERATION  
**Balance:** unchanged from P1-0.11.0

## Why 0.11.2 exists

P1-0.11.1 shipped its new UI stylesheet successfully, but `ui-patch.js` contained a missing closing brace in `syncLaneChips()`. The browser therefore failed to parse the entire behavior layer.

Observed consequences on target iPhone PWA:

- detached structure button was hidden by CSS;
- `ACTIONS` remained as the old button text but inherited the new circular reference-button styling, producing an oversized label;
- lane-local action trays never initialized;
- direct lane movement / Waypoint target chips never initialized;
- ability READY / cooldown presentation never initialized.

This was an implementation failure, not a human rejection of the 0.11.1 interaction design.

## 0.11.2 repair

- closes the malformed function correctly;
- keeps the reference button as `?` even in the static HTML shell;
- restores lane-local action tray behavior;
- restores `WALK HERE` and `WAYPOINT HERE` lane-card targets;
- restores READY / cooldown / DOWN ability state rendering;
- bumps app, advertised build, updater, worker cache and versioned asset URLs to P1-0.11.2.

## Deliberately unchanged

No combat or economy variable changed:

- unit/tower values;
- enemy pressure;
- Guard regeneration;
- Gate damage;
- battle gold;
- purchase costs/effects;
- ability effects/cooldowns;
- Reclamation trigger/cadence;
- Commander travel/reform.

The next human run remains a UI comparison against the same P1-0.11.0 balance.
