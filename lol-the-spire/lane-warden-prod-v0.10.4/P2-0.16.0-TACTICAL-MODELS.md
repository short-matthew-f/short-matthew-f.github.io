# Lane Warden P2-0.16.0 — Tactical Models

## Outcome

The Living Lanes renderer now presents the battle as animated tabletop miniatures instead of abstract dots. The simulation remains cohort-based and unchanged; this release replaces only its visual projection.

## Readability language

- Warden: singular, 130% scale, teal-and-gold presence base.
- Ironjack: broad golden armored figure, compact 3–5 member formation.
- Slingline: bow silhouette, shallower rear formation, ranged-support tracer.
- Enemy line: ordinary red formation.
- Raider: smaller orange figures in a loose fast formation.
- Brute: one or two 162%-mass dark-red bodies.
- Siege Ram: one large chassis with two crew silhouettes.
- Friendly/hostile base rings and palettes remain readable below the model detail.

March, engage, support, fall, reinforcement, slow, Warden Presence, Rally, damage, casualty loss, and objective breach each have a compact visual treatment. Cohort HP reduces visible formation members before the bar empties.

## Rendering architecture

`simulation entity → visual archetype → source asset → processed atlas frame → presentation state`

Mappings and source records live in `assets/manifests/tactical-models.json`. Runtime code fetches that manifest; renderer code does not couple simulation IDs to filenames. Selected animation poses are baked into a 55 KB atlas so the target phone pays no skeletal-animation or multi-model WebGL cost during battle.

## Source decision

Quaternius was selected as the strongest compatible source because the baseline-1.7 strategy already recommends it first for characters, its models survive the actual three-quarter tactical projection, and the authoritative pack pages and included license files identify the selected packs as CC0. KayKit remains a valid future comparison set but was not mixed into this first pass because one coherent source family produced a complete critical roster.

## Preserved systems

No battle rules, cohort stats, reinforcement cadence, encounter tuning, reward data, reward resolution, save schema, progression, economy, Commander mechanics, Reclamation, Last Stand, or deployment capacity changed.
