# R01-B Human Playtest 02 — Disposition

**Source:** `evidence/R01-B-human-playtest-02.json`  
**Build:** M0-0.2.2 / R01-B / DL-001  
**Disposition:** Strong exploratory evidence that the intended Twin Toll fork can be perceived and acted on **under informed play**. It is **not** independent-teaching evidence because the tester had already been told the encounter's intended sacrifice/breach thesis.

## Result

- Siege + delay deployment.
- Win at **186.6s**.
- North Guard broke at **144.12s**.
- South Bastion broke at **160.7s**.
- Gate fell at 186.6s with **63.8% Core** remaining.
- 120g spent: one North Push and one North Overdrive.
- Debrief: `sacrifice=yes`, `guardRead=clear`, `goldFork=yes`.
- Battlefield interaction remained usable with the tap-through HUD.

## What this supports

1. R01-B can generate the intended sequence: real breach pressure → conscious lane sacrifice → Guard break → Bastion loss → Gate conversion.
2. DL-001 materially improved Guard/gold/fork legibility compared with the prior Siege + delay run that lost with 171g unspent and zero interventions.
3. The human decision thesis is supported at an exploratory **informed-play** level.

## What this does not support

- That an uncoached player would discover the sacrifice thesis unaided.
- That the 186.6s battle duration satisfies the 5–10 minute ordinary-battle target.
- That the sacrifice clock was sufficiently dangerous; the Core retained ~64% at victory.
- Shipping balance or formal strategic acceptance.

## Carry-forward

- Freeze DL-001 for R01-C pacing work.
- Add first-appearance telemetry for the fork cue so future evidence records when the UI presented the decision.
- Preserve an independent future UX experiment for offscreen threat attention rather than conflating it with pacing tuning.
