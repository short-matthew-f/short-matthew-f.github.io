# T6-0.5.1 — Targeted Readability Intervention

This build is a rerun target for the frozen **LW-T6-001** declaration after the first human run failed at 5/8 correct, 6.67 s median correct-response time, three correct responses over six seconds, and three camera-tax prompts. The declaration thresholds, prompt plan, fixture, parameter revision, and R02-D gameplay remain unchanged.

## Changes allowed in this build

1. **Opening orientation** — for the first 80 battle seconds, a small noninteractive legend above the lane strip identifies `◆ YOU`, `✦ RIVAL`, and the friendly-front bar. It teaches the lane-strip grammar without naming the answer lane.
2. **Threat ownership** — the existing severity badge now displays the owning lane name, and that lane receives a matching nonblocking outline in the lane strip while the alert is active.
3. **Bastion comparison** — each Bastion badge gets a proportional remaining-state bar and severity color. When the same `>= 3` percentage-point uniqueness condition used by the harness is satisfied, the uniquely shortest Bastion receives a compact emphasis.
