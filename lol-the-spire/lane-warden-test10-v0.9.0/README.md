2. Play Sequence A without leaving the app.
3. Answer the five comprehension questions.

6. Complete the five presentation questions.

## Content under test

Both sequences include Core fall, Warden Last Stand escalation, Bulwark Detonation, Gate destruction, Ember consequence, and an onward/run-end transition.

Sequence A is a payable-loss state; Sequence B is an unpayable terminal-loss state. The harness intentionally does not label those states before the comprehension questions.
